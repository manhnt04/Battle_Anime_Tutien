# Battle Anime Tu Tiên (Võ Lâm Sinh Tồn - Cửu Kiếm Quy Nhất)

Game 2D Battle Royale phong cách Võ Lâm Tu Tiên & Anime trên nền Web (HTML5 Canvas & PixiJS).

## 🎮 Tính năng nổi bật
- **Hệ thống vũ khí đa dạng**: Kiếm pháp, Đao pháp, Thương, Quạt phiến, Cung tên và các Thần Khí Anime/Tu Tiên huyền thoại (Zangetsu, Excalibur, Enkidu, Gate of Babylon,...).
- **Vòng bo & Airdrop**: Cơ chế bo độc thu hẹp dần và hòm tiếp tế rơi từ trên trời.
- **Kỹ năng & Chiêu thức**: Hiệu ứng chém gió, phi kiếm, lướt kiếm khí, chưởng pháp, kỹ năng tối thượng.
- **AI Bots thông minh**: Tự động nhặt đồ, di chuyển vào bo, combat và né chiêu.
- **Đồ họa tối ưu**: Kết hợp Canvas 2D và bộ tăng tốc đồ họa PixiJS.
- **Hỗ trợ đa nền tảng**: Chơi mượt mà trên PC và thiết bị di động (Mobile Touch Controls & Joystick).

## 🚀 Hướng dẫn chạy game
Chỉ cần mở file `index.html` bằng bất kỳ trình duyệt web hiện đại nào hoặc chạy với một HTTP server local:

```bash
# Sử dụng Python
python -m http.server 8080

# Hoặc sử dụng Node npx
npx serve .
```

Truy cập: `http://localhost:8080`
